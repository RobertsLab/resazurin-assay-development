`data/clam/20260528-rphi-36C`


## DESCRIPTION

Manila clams (_Ruditapes phillippinarum_) from both tweed/blue control/selected (low salinity tolerance) were distributed across six 12-well plates. Clams were submerged in 4mL of resazurin working solution (prepared 20260528 by SJW) and incubated at 36<sup>o</sup>C. Resazurin fluorescence was measured every 30mins using a Synergy HTX (Agilent) plate reader.

---

### FILES

- `*ImageJ.csv`: Area measurements generated by ImageJ. A corresponding annotated image can be found in the `images` directory.

- `layout.csv`: Metadata file containing plate layout info, sample IDs, sample area measurements, etc.

- `*T<N.N>.txt`: Data files output by the plate reader for each plate. The `<TN.N>` portion of the file name represents the time of measurement in hours, from the beginning of the experiment.
