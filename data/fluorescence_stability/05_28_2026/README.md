`data/fluorescence_stability/05_28_2026`

### DESCRIPTION

9 Pacific oysters were incubated at 36C for 3 hours in 5ml resazurin working solution in a 12-well plate, including three blank wells. After the heat stress, the working solution was split evenly and transfered to 15ml conicals (i.e. ~2.5mLs in one conical and the remaining ~2.5mLs into another). One set stored at room temp, one stored on ice. Resazurin flourescense measured periodically using 1.5mL from conical in a 12-well plate. Resazurin solution was returned to 15mL conicals after each measurement.

T0.0 corresponds to the first measurement taken at the end of the heat stress.

---

### FILES

- `layout.csv`: Metadata file containing plate layout info, sample IDs, sample area measurements, etc.

- `*T<N.N>.txt`: Data files output by the plate reader for each plate. The `<TN.N>` portion of the file name represents the time of measurement in hours, from the beginning of the experiment.
